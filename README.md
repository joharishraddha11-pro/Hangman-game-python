# Hangman Game

This is a simple **Hangman Game** developed using Python as part of my Python Internship – Task 1.

## Description

Hangman is a word guessing game where the player tries to guess a hidden word by entering one letter at a time. The player has a limited number of incorrect guesses before the game ends.

## Features

- Random word selection
- User guesses one letter at a time
- Displays correct guessed letters
- Tracks incorrect attempts
- Shows win or lose message
- Simple command-line interface

## Technologies Used

- Python
